# WebAvanzadoII - Inventory Management System

This project was created and deployed from VS Code with GitHub Copilot.

## Project Status
- ✅ Django 5.1.5 Backend with REST API
- ✅ MongoDB Integration with MongoEngine
- ✅ WebSocket Server (Pure Python, no Redis)
- ✅ Bootstrap 5 Frontend
- ✅ Docker Containerization
- ✅ CI/CD Pipeline with GitHub Actions
- ✅ Comprehensive Testing Suite

## Architecture
- **Backend**: Django + MongoDB (no Redis)
- **WebSockets**: Pure asyncio implementation
- **Frontend**: HTML5 + Bootstrap 5 + JavaScript
- **Deployment**: Docker + GitHub Actions

## Deployment Ready
This project is ready for deployment to platforms like Railway, Render, or Heroku.
